# Notes App API

## 📌 Description

An asynchronous note management web application integrated with an external REST API backend. The application handles full data creation, deletion, and archiving workflows with real-time network request synchronization, visual loading indicators, and modular interface components.

## ⚙️ Setup Instructions

1. **Prerequisites**
   - Node.js 24 or higher.
   - Git installed on your system.
   - PNPM 10 installed on your system (Optional).

2. **Clone the Repository**

```bash
git clone https://github.com/Fikri-Rouzan/notes-app-api.git
cd notes-app-api
```

3. **Install Packages**

```bash
# Using npm
npm i

# Using pnpm
pnpm i
```

4. **Run the Program**

```bash
# Using npm
npm run dev

# Using pnpm
pnpm dev
```
